## Source discrepancies and testing limits

- Drag-to-Pan is direct pointer translation in the original; it has no inertia. No fictional momentum was added.
- View Transitions uses a CSS overlay in the supplied original; declaring a transition name alone does not invoke the browser API. Native shared-image opening/closing is an enhancement, with the original style of fallback retained.
- The original kinetic-marquee sign is inconsistent with its wrap condition, causing the nominal left track to move right without wrapping. The integration fixes the sign/wrap and retains its velocity formula and movement intent.
- The original gradient-stroke transparent currentColor renders filled text in this Chromium run. The integration uses a real unfilled SVG gradient stroke, preserving the intended 6s linear movement. This is a rendering correction, not a claim of pixel identity with the broken source output.
- Mesh uses the source four-blob Canvas mechanism. A light transparent surface and reduced raster resolution are deliberate changes; normalized movement still uses the original virtual 2× dimensions. This preserves motion speed while reducing rendering cost.
